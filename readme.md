第二次作业：用户注册页面
作业内容
制作HTML5用户注册页面，综合使用表单、表格、列表，使用header、main、footer语义标签，hr横线分隔各个模块。表单提交后在浏览器控制台打印表单数据。

使用标签
语义标签：header main footer
分割：hr
表单：form input label select option textarea button
列表：ul ol dl dt dd
表格：table thead tbody tr th td

遇到的困难
1.label两种用法：for+id 和嵌套包裹，练习后掌握。
2.表单提交页面刷新：通过js e.preventDefault()阻止默认提交，才能打印数据。
3.表格单元格合并colspan容易写错，反复调试完成。

运行
VSCode打开，Live Server运行，F12打开Console，填写表单点注册查看输出。
